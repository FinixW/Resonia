# RBGA：鸣域通用 BGA 场景模型（v1）

目的：把各种游戏的 BGA 动画（EZ2DJ 的 STR、DJMAX 的 VCQ/VCE 等）翻译成**同一种纯 JSON 模型 + 图片素材**，由同一个渲染引擎（`src/rbga.js`，游戏页与 Studio 共用）画出来。这样它们可以：写进 `.rsc` / `.rsm`、导出成视频、将来用同一个编辑器制作，再转换成其他格式。

引擎源码在 `src/rbga.js`；改动后运行 `python3 tools/embed-rbga.py` 把它嵌回 `index.html` 和 `studio/index.html`。

## 模型

```json
{ "rbga":1, "w":640, "h":480, "fps":60,
  "clips":{ "片段id":{ "frames":600, "sprites":[
      { "tex":["贴图id", "…（序列图）"], "life":[起帧,止帧], "kf":[ {"f":0, "v":{…}, "d":{…}} ] } ] } },
  "tracks":[ [ {"f":0, "clip":"片段id", "mode":"once"} ] ] }
```

- **虚拟屏幕** `w×h`：渲染时等比缩放放进目标画布并裁剪（EZ2DJ 640×480，DJMAX 800×600）。
- **轨道** `tracks`：序号越大越靠上。每条轨道是一串按帧排序的事件，某一帧生效的是最近一个 `f ≤ 当前帧` 的事件。
  `mode`：`once` 播一次（播完不再显示）、`loop` 循环、`stop` 清空这条轨道。
- **片段** `clips`：`frames` 为总帧数；片段内的帧号 = 当前帧 − 事件的 `f`。
- **精灵** `sprites`：一张（或一组序列）贴图 + 关键帧。可选 `life:[起,止]` 限定只在这段帧里显示。
- **关键帧**：某一帧的状态 = 最近一个 `f ≤ 当前帧` 的关键帧 `v + d × (当前帧 − f)`（`d` 省略表示不变化）。
  线性插值用 `d=(下一键−本键)/间隔` 表示，“绝对值 / 增量”两种记法也都能表示。

`v` 的字段（缺省值见 `rbga.js`）：

| 字段 | 含义 |
|---|---|
| `x`,`y` | 位置（虚拟屏幕像素） |
| `px[4]`,`py[4]` | 四角相对位置（只用左上、右上、左下三点决定平行四边形） |
| `rot` | 旋转（度，绕 `x,y`） |
| `uv:[u0,v0,宽,高]` | 贴图矩形（0~1；超出 1 时按重复铺开，用于滚动的海浪、云层） |
| `col:[r,g,b]` | 染色（乘，0~255；全 255 表示不染色） |
| `a` | 不透明度 0~1 |
| `bl` | `normal` / `add` / `multiply` / `exclusion` |
| `seq` | 序列贴图的播放速度（张/帧） |

## 在 .rsc / .rsm 里

谱面的 `scene` 字段存放模型，贴图是清单 `media` 里的图片素材，素材 id = 模型里的贴图 id（游戏 v0.9.35 起读取）。
`bga[]`（静态图片/视频事件）与 `scene` 可同时存在。

## 在插件里

插件在 `makeSong` 里传 `bgaModel`（模型）和 `bgaTex`（`{贴图id: Canvas / ImageBitmap}`），宿主负责渲染、保存和导出视频。老的 `bgaScene.render(...)` 仍然可用，但不能写入 `.rsc`。

## 已验证

EZ2DJ（STR）与 DJMAX（VCQ/VCE）两个插件已改为输出 RBGA，新引擎与原来各自的渲染代码逐像素对比，差别不超过 1 级灰度（各取 8 个时间点）。
